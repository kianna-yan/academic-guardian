# 2026-11-03 五端一致性修复（登录页 · 对话区 · 侧栏）

## 任务

演示前的最后一轮体验修复，来自队友自己点五端时记下的四个问题：

1. 登录页没有教师端的初始密码，五个端口和密码的排版也不整齐；
2. 辅导员端 AI 对话区圈出来的三句快捷提问词是学生端的，跟当前端口对不上；
3. 左侧任务栏只有学生端在 AI 对话里点得动，其他端得先退出对话才能跳转；
4. 家长端、教务端（以及教师端）侧栏没有「AI 顾问 → 对话」这个入口。

## 约束

- 只改前端（`web/src`），不动后端接口与引擎逻辑，避免影响已经跑通的取数与问答；
- 五个端共用同一套组件，改动必须是「按角色取配置」，不能为某个端打补丁；
- 修完要能逐端复现验证，不接受「看起来好了」。

## AI 给了什么

- **登录页**：把 tab 的 `grid-template-columns: repeat(4, 1fr)` 改成 5 列（教师端原来被挤到第二行）；
  初始密码区从 2×2 卡片改成「端口 / 账号 / 初始密码」五行对齐表格，补上教师端 `2024014501 / 4444`。
- **对话区串端**：根因不在文案表上（`DEFAULT_SUGGEST` 本来就是按角色分的），而在
  `App.vue` 里那个 `watch` —— 登录时是「身份先落地、路由后跳」，watch 触发那一刻 `route.name` 还是
  `login`，被 `if (!isLogin.value)` 直接跳过，于是 `chat.ensure()` 一次都没跑到，辅导员/家长端
  继承的还是启动时那份学生端的问候语和建议词。改法是让 `ChatHome` 自己 `ensure(props.role)`，
  并给建议词加上「属于哪个端」的标记（`suggRole`），对不上就立刻换回本端默认提问。
- **侧栏跳转**：`SideBar.vue` 里 `/student` 写死了三处（`inChat` / `goChat` / `onNav`），
  其他端在对话模式下点侧栏，`homeMode` 不会切回 `dash`，页面自然不动。改成按 `HOME_OF[role]` 取本端首页。
- **入口缺失**：`modules.ts` 给教务端、教师端、家长端补 `AI 顾问` 分组，与学生端同一套样式。

## 人工判断

- **否掉了「把建议词写死成当前端」的方案**：那样一旦后端按上下文推了新建议词（比如刚查完名单后
  提示「给他生成谈话要点」），前端也会被覆盖掉。改成记来源 + 失配兜底，两种来源都能用。
- **顺手补了顶栏的角色标签**：`TopBar.vue` 的角色映射漏了 `teacher`，教师端右上角会显示成
  「端 · 2024014501」，中间空一格。这属于同一类「按角色渲染的字典漏项」，一并补齐。
- **`fill()` 与 `watch(active)` 打架**：验证时发现点「初始密码」表格里的任何一行都登不进去，
  控制台提示「请输入密码」——`watch(active)` 的清空动作排在填值之后，把刚填的密码抹掉了。
  改成显式的 `switchRole()`，只在用户点 tab 时清空。这个是照做演示步骤时才暴露出来的，
  单看代码不容易发现。
- **没有替队友决定部署**：改的是本地源码与构建产物 `web/site`，线上那台
  （`academic-guardian.app.workbuddy.host`）需要重新发布才会生效，等队友确认后再发。
