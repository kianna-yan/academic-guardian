# AI 协作记录

本目录记录开发过程中与 AI 的关键协作：提出什么问题、拿到什么方案、人工做了哪些判断与改动。

## 为什么要记

赛制要求提交完整、细粒度的开发过程。代码只能证明"做了什么"，不能证明"怎么想出来的"。这份记录补的是后者——尤其当代码有相当比例由 AI 辅助生成时，需要说清楚**哪些是 AI 给的、哪些是我们改的、为什么这么改**。

## 写法

每条记录四段，不要写成流水账：

1. **任务** —— 当时要解决什么
2. **约束** —— 给 AI 的硬条件（技术栈、不能碰的东西、性能要求）
3. **AI 给了什么** —— 方案摘要，明确标出被采纳和被否掉的部分
4. **人工判断** —— 为什么采纳/否掉，落地时改了什么

文件名 `YYYYMMDD-主题.md`。

**原则：只记真实的。** 记一次被 AI 带偏、然后自己纠正的过程，比记十次"AI 完美完成任务"可信得多。
