# 2026-11-04 第三轮体验优化

本轮针对 v2 交付后反馈的四个问题做修复，全部在真实浏览器里逐项断言过。

## 一、教师端「历年真题」「网课资源」合并为一个入口

**问题**：侧栏「教学资源」分组下挂着「历年真题」「网课资源」两项，但两项都指向
`/teacher/resources`（同一页的两个页签），点哪个都进同一页，等于把一条路画了两遍。

**改法**：`web/src/config/modules.ts` 里 teacher 的 resources 分组只留一项
「历年真题 · 网课」，hint 写明「上传历年期末试卷与网课视频/讲义，学生在「学习资源」里下载」。
页面内部的两个页签不变，只是侧栏不再重复。

## 二、教师端点班级卡片后下方数据不更新

**问题**：点「计科2402」卡片，只有下方学生名单跟着筛，期中成绩分布、逐周出勤、
六项统计、逐次作业全都还是整门课的数字。卡片看上去点了没反应。

**根因**：`classFilter` 只被 `rows`（名单）消费；四张图直接绑的是 `course.dist` /
`course.attend.weekly` / `course.hw.items` / `c.risk`，这些是后端按「整门课」算好的汇总，
跟前端选了哪个班没有关系。

**改法**（`web/src/views/TeacherView.vue`）：

- 新增 `activeStudents`（当前班级的学生集合）与 `isAllClass`；
- 新增 `distOf()` / `weeklyOf()` / `hwItems`：用学生级的 `midterm`、`attendance[]`、
  `homework[]` 明细按班级重算，分档口径与后端 `BUCKETS` 完全一致
  （90+ / 80-89 / 70-79 / 60-69 / <60），作业「迟交也算交」与后端一致；
- 新增 `classAgg`：按班级算均分、中位数、标准差、最低/最高、及格率、旷课迟到人次；
- `stats` 分两支：看「全部班级」时用后端整课数据（权威），选班时按该班重算；
- 「全部班级」卡片改用 `allCounts`，避免选班后总数也跟着变；
- 图表区前面加一条橙色 `scope-bar`：「四张图已切到 计科2402（40 人）；点「全部班级」看整门课」，
  让「切了没有」一眼可见。

**验证**（自动化断言）：

| 范围 | 修课学生 | 期中均分 | 及格率 | 出勤率 | 作业率 | 需关注 |
| --- | --- | --- | --- | --- | --- | --- |
| 全部班级 | 240 | 77.3 | 96.2% | 88.4% | 91.5% | 45 |
| 计科2401 | 40 | 77 | 97.5% | 83.6% | 93.3% | 4 |

底部汇总同步变化：全部班「旷课 389 / 迟到 212」→ 计科2401「旷课 62 / 迟到 30」；
中位数 77 → 76.5、标准差 10 → 10.7。切回「全部班级」后数字完整还原。

## 三、课表状态改完不显示 + 「今天」显示不全

### 3.1 状态改完课表不刷新（真 bug，两层）

- **后端层**：`engine/checkin.py` 的 `upsert()` 返回的 row 里只有 `understand`，
  没有 `state` / `state_label`；而课表读取时（`timetable()` 第 166 行）是把
  `understand` 映射成 `state` 输出的。前端 `onSaved(row)` 读的是 `row.state`，
  拿到 `undefined`，于是「待记」消失但也不显示「听懂」——看起来像没保存。
- **前端层**：`ScheduleView.vue` 的 `onSaved()` 只遍历 `data.slots`，
  而课表网格渲染的是 `data.cells`（后端把同一批课按 `weekday@period` 又存了一份，
  JSON 序列化后是两份独立对象）。即使 state 有值，网格也不重绘。

**改法**：

- 后端 `upsert()` 返回前补 `row["state"] = row["understand"]` 与
  `row["state_label"] = UNDERSTAND[...]["label"]`，与读取口径统一；
- 前端 `onSaved()` 抽一个 `patch()`，同时打到 `slots` 和 `cells` 的所有分桶上，
  并对老后端做 `row.state || row.understand` 兜底。

**验证**：点「概率论与数理统计（待记）」→ 选「听懂了」→ 点「记下这节课」，
网格该格立刻变成 `lesson full` 并显示「听懂」，无需刷新、无需跳学习轨迹。

### 3.2 「今天」显示不全

**问题**：表头周三那列显示成 `10/2` + 一个被裁掉一半的「今天」标签。

**根因**：`.today-tag` 用 `position: absolute; top: -7px; right: 6px`，浮在日期右上角；
列宽窄时直接盖住 `10/21`，`top: -7px` 又超出表头容器被裁。

**改法**：表头改成两行结构（`周几` / `10/21 + 今天`），`.today-tag` 去掉绝对定位，
与日期在同一行 flex 并排，加 `white-space: nowrap`。表头高度从 40px 变 44px。

**验证**：周三列 `date = "10/21"`、`overlap = false`、`overflow = false`。

## 四、智慧森林的树美化

原实现是几个纯色圆叠成树冠、`rect` 当树干，辨识度有了但很「贴纸感」。

**改法**（`web/src/components/CounselorForest.vue`）：

- 统一底座：地面投影椭圆 + 锥度树干（`path` 下宽上窄）+ 树干右侧高光，
  让树「长在地上」而不是飘着；
- **绿（正常）**：三层树冠叠加 + 左上高光 + 三颗小果实（橙/橘/黄各带高光点）；
- **黄（关注）**：冠形略散，亮黄叠在深橙上，下方三片飘落叶；
- **红（预警）**：七段分叉枯枝（主干粗、末梢细）+ 三颗带高光的红果 + 一片落叶；
- viewBox 从 `60x80` 改为 `64x84`，hover 时整棵树 `scale(1.06)`。

**验证**：6 个班 240 棵树全部渲染（195 绿 / 37 黄 / 8 红），每棵 SVG 18 个子元素，
viewBox 正确，地面阴影存在。
